
# Dataset Sources and Licensing

This project uses the POPE benchmark and MS COCO annotations
for research on object hallucination in vision-language models.

## 1. POPE Benchmark

- Source: https://github.com/RUCAIBox/POPE
- Repository license: MIT License
- Paper: Evaluating Object Hallucination in Large Vision-Language Models
- Authors: Yifan Li et al.
- Conference: EMNLP 2023

The POPE benchmark is used to evaluate object hallucination
in vision-language models.

The original source and copyright notices are retained.
The POPE repository's MIT license is included for reference.

Note: The MIT license for the repository should not be
interpreted as overriding rights in third-party source data.
